使用說明

這個工具在做什麼

總共會產出三顆獨立的 exe：這個工具本身（你現在看到的畫面，用來設定並編譯安裝檔）、 編譯出來的安裝檔（給終端使用者雙擊安裝軟體的 macOS 風格拖曳視窗）、 以及解除安裝程式（安裝時自動放進安裝目錄）。三者職責分開， 本工具執行「開始編譯安裝檔」時，會另外呼叫系統上的 PyInstaller 現場編譯出後兩者。

環境需求

操作這個工具的電腦要先安裝：pip install pyinstaller pywebview pywin32。 前兩者是必要的，開啟本工具時會自動檢查、缺少會跳提示；pywin32 選用，只影響捷徑功能。 本工具不論是直接用 python gui_config.py 執行，還是打包成 exe 使用， 都需要這台電腦具備上述環境才能真的編譯出安裝檔。

基本流程

依序填寫應用程式名稱、安裝資料夾名稱、版本、發行者、安裝檔名，選擇要打包的應用程式資料夾 （裡面放你的軟體本體），再從下拉選單選出主要執行檔，最後選擇 PNG 與 ICO 圖示即可開始編譯。

主要執行檔是什麼？

指使用者安裝完成後，實際會被執行的那個 .exe。這個資訊會用來建立捷徑、 偵測程式是否正在執行中、以及安裝完成後「立即執行」功能。

安裝資料夾名稱是什麼？

跟應用程式名稱是分開的兩件事：應用程式名稱是顯示給使用者看的，可以是中文； 安裝資料夾名稱決定實際安裝路徑長什麼樣子，留空會沿用應用程式名稱。 如果應用程式名稱是中文，建議另外填一個純英數字的資料夾名稱，避免路徑含中文在少數環境下出問題。

EULA 留空會怎樣？

留空的話，使用者安裝時不會看到同意頁面，直接進入安裝畫面。

相依元件偵測 / 檔案關聯 / PATH 有什麼限制？

相依元件目前只做偵測與提示下載連結，不會自動安裝該元件。 檔案關聯與 PATH 設定需要以系統管理員權限執行安裝程式才會生效（本工具產生的安裝檔預設就會要求管理員權限）。 勾選檔案關聯後，可以另外勾選「自訂這個副檔名的文件圖示」指定一顆專屬 ICO； 不勾選的話，文件圖示會直接沿用應用程式本身的圖示。

安裝端實際會做的事

單一實例鎖、EULA（有設定的話）、覆蓋安裝偵測（偵測到已安裝版本會比較版本新舊， 版本較新才會問是否更新，版本相同或較舊會提示使用者）、相依元件提示、磁碟空間檢查、 執行中偵測、真實複製進度、複製後 checksum 完整性驗證、失敗自動回滾、 登錄表寫入、捷徑、檔案關聯、PATH、安裝清單與安裝紀錄。

靜默 / 命令列安裝

編譯出來的安裝檔支援命令列參數，給企業批次部署用：
Setup_XXX.exe /S（靜默安裝，不開視窗）
Setup_XXX.exe /S /D=D:\Apps\MyApp（指定安裝路徑）
Setup_XXX.exe /S /NODESKTOPSHORTCUT（不建立桌面捷徑）
執行結果反映在 exit code（0 = 成功），這個數字不會顯示在畫面上， 要用 echo %errorlevel% 檢查；同時也會寫一份 log 檔留底。

解除安裝行為

只刪自己安裝時放進去的檔案（照安裝清單），不會動到使用者事後自己在安裝目錄 產生的檔案；清單內的檔案刪完後，資料夾如果真的清空了才會整個移除， 有其他剩餘內容就只刪解除安裝程式本身，資料夾保留。

已知限制

目前沒有數位簽章（第一次執行大概率會被 SmartScreen 攔）； 相依元件只做偵測不會自動安裝；沒有多語言介面； 極少數沒更新過的 Windows 10 可能需要另外安裝 WebView2 Runtime。

常見問題

若編譯過程中顯示找不到 ui 資料夾，代表 ui/index.html 沒有跟這個工具放在一起； 若打包時卡在「存取被拒」，通常是上一次編譯出來的 exe 還在執行中或被防毒軟體鎖住； 若編譯失敗，請確認 PyInstaller 已正確安裝在執行環境中。
