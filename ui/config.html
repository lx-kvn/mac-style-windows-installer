配置您的安裝程式資訊

安裝路徑（例如 C:\Program Files\這裡）會用這個名稱，跟上面的應用程式名稱是分開的兩件事——應用程式名稱可以是中文，用來顯示給使用者看；如果應用程式名稱是中文，建議在這裡另外填一個純英數字的名稱，避免路徑中出現中文字在少數環境下造成讀寫問題。
未選擇資料夾
用於建立捷徑、偵測執行中狀態、安裝完成後立即執行等功能。
未選擇檔案
用於安裝視窗內顯示的精細圖標。
未選擇檔案
用於安裝檔在 Windows 檔案總管中顯示的外觀。
留空則安裝時不顯示同意頁面。可以新增多種語言的版本，開發者自行提供每種語言的文字；終端使用者安裝時會依系統語言自動挑選對應版本，挑不到才會用下面指定的「預設/回退語言」。
當終端使用者的系統語言沒有對應到任何已提供的 EULA 版本時，顯示這個語言的版本。
安裝時僅會偵測系統是否已安裝，缺少時提示使用者前往官方頁面下載，不會自動安裝。
未選擇檔案
不勾選的話，文件圖示會直接沿用應用程式本身的圖示。
上面輸入多個副檔名時，這裡會列出每一個，可以各自選擇不同的 ICO 圖示；不選就沿用上面設定的圖示（或主程式圖示）。例如 .a 用一張圖示、.b 用另一張。
預設會把整個安裝目錄加進 PATH。如果應用程式除了主程式外，還附了一支獨立的命令列工具（例如放在子資料夾），可以在這裡另外指定那支執行檔，改成只把它所在的目錄加進 PATH。
預設所有檔案都裝進主安裝目錄（可能在 Program Files，需要系統管理員權限才能寫入）。在這裡列出的檔案會改成裝到 %LOCALAPPDATA%\Programs\<安裝資料夾名稱>（使用者自己的目錄，不需要系統管理員權限），適合單獨拆出來的命令列工具，讓使用者事後執行它不用每次都要提權。如果「加入 PATH 的執行檔」剛好也列在這裡，會自動改成把這個使用者目錄加進 PATH，不用另外設定。
適用於應用程式有註冊 Windows 檔案總管殼層擴充功能（Shell Extension，例如右鍵選單擴充 DLL）的情況——只要檔案總管還在執行，就會鎖住這類 DLL，導致更新覆蓋時無法覆寫。勾選後，更新覆蓋安裝時會先關閉檔案總管、刪除完畢後自動重啟；使用者畫面會短暫閃爍、所有檔案總管視窗會關閉，非必要（沒有殼層擴充功能）不建議勾選。

缺少編譯安裝檔所需的環境
這個工具本身已經正常開啟，不受影響；但「開始編譯安裝檔」這個動作， 需要另外呼叫系統上的 PyInstaller 去實際編譯出安裝檔，缺少下列項目的話會編譯失敗：
安裝指令（在命令提示字元執行）：
pip install pyinstaller pywebview pywin32
如果連 Python 都還沒裝，請先前往官網下載安裝，安裝時記得勾選「Add python.exe to PATH」。
